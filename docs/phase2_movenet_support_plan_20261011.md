# Phase 2：原骨架的幾何支持警示試驗

2026-10-11（台灣）。接續五球全圖比較；在本試驗產生警示前固定規則。
這是獨立離線 sidecar，不替換正式模型或既有警示，也不重跑任何 pose／tracker。

五球比較顯示：587格中281格唯一對應、290格歧義、16格無候選。
003原18格重大錯位中14格歧義，因此不能只挑一個新模型骨架後宣稱修復。
本試驗回答較有限的問題：**所有符合既有幾何條件的 native 框，是否都與原骨架的軀幹範圍衝突？**

## 固定規則

1. 只讀封存 MoveNet 六槽輸出、封存 CSRT、原 raw CSV 與 capture。人工標籤只由評估端讀取。
2. 候選條件完全沿用五球比較：native 正面積框與 CSRT 有正交集，四肩髖位於原圖及 CSRT 半開矩形內。
3. 原 raw 四肩髖任一缺失／非有限，或沒有幾何候選，記為 `insufficient_evidence`。
4. 有至少一個候選 native 框同時包含原 raw 四肩髖，記為 `no_warning`。
5. 否則每個候選都至少有一個原肩髖點在框外，記為 `warning`，原因
   `all_compatible_native_boxes_contradict_raw_torso`。
6. 歧義仍保存；全集衝突不需要挑選單一人物。不同槽不得各自提供部分支持後拼成一個人。
   不用 score、IoU 或人工誤差解歧義，不設定分數 cutoff、padding、容忍像素或持續格數。

`no_warning`僅表示存在幾何支持；不是位置、身份或解剖正確的證明。
`warning`僅表示兩種模型假設的範圍衝突；不等於已確認重大失效或換人。
native框本身可能偏窄或錯誤，因此必須量測誤報，不能預設本規則有效。

## 固定分母與評估

五球592格全部保存，各片frame0不計成效，主要分母587格。人工confirmed major為正例，
完整覆核的其餘非排除格為負例；uncertain／not_observable按原定義排除。
模型證據不足仍保留在主要分母，以未發出警示計算FN／TN，另列其正例／負例分布。

逐片及總計列原tracking screen、此新提示、兩者聯集的TP／FN／FP／TN、precision／recall／FPR；
另列決策覆蓋、警示及缺證據格數、逐格範圍與原重大區段的涵蓋率。
原screen直接沿用既有tracking：selection非selected或warnings非空，不刪原警示。
只評估原MediaPipe輸出的失效提示；不把原GT轉成新MoveNet骨架的正確標籤。

這批是已知開發資料，沒有未見資料泛化結論。無新通過線、無參數搜尋、無重推論，
無論結果好壞都保存；任何後續規則變更須另行說明，不能覆寫本試驗。
本試驗仍不能獨立證明自動身份追蹤或各關節準確，Phase2狀態依實際缺口判定。
