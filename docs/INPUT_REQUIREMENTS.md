# 輸入影片需求

更新日期：2026-10-06。供獨立影片專案透過共用交付資料夾提供成品。
分析專案需要可獨立使用的影片與說明資料，不依賴供片專案的程式碼。

## 1. 投手與數量

- 目前只需要 **1 位：山本由伸**。正式 5 支素材已備妥，本次不新增投手。
- 後續小量交付驗證可先增加第 2 位；挑選身分、左右投明確，且能取得同視角完整單球的投手。這是後續素材規劃，尚未開始收片或擴充分析。
- 優先同一投手、同一場次或接近的球季與鏡位；球種與場次資訊已知時保留，未知就標未知。
- 不需要一次提供 8–10 位投手；先取得少量可人工覆核的可靠素材。

## 2. 每位投手需要幾顆球

- **交付目標每位 5 顆合格單球；最低小量試交付為 3 顆。** 山本的正式 5 顆維持原樣。
- 一顆可以排查故障，3–5 顆便於檢查是否重複出現追蹤／關節問題；這不是足以建立完整投手 profile 或統計動作比較的樣本量。
- 數量只計入身分、視角、速度與動作完整的可用球；不以重複同一球湊數。

## 3. 影片規格

| 項目 | 需求 |
|---|---|
| 格式 | 可正常完整播放的 MP4，優先一般相容的 H.264；檔案不得損壞或截斷。 |
| 最低解析度 | **目前沒有經驗證的固定像素下限。** 必須保留可辨識全身與關節的原生畫質；不可把提高輸出像素當成增加細節。 |
| 解析度參考 | 現有正式素材為裁切後約 434–532 px 寬、598–676 px 高。這是既有樣本範圍，不是已驗證的最低標準；後續供片優先保留原生 720p／1080p 來源細節，不能裁掉投手肢體。 |
| 每秒格數 | 交付目標原生 29.97／30 FPS 或以上；原生 59.94／60 FPS 更利於分辨出手時間。保留原始格數與速度，不補假影格。 |
| 低 FPS | 目前可接收低於 29 FPS 的正常速度影片，但事件時間較粗，不能當成高精度出手參考；既有相容上限為 240 FPS。 |
| 時間軸 | 固定格率，逐格時間連續、順序正確；畫面尺寸全片一致。 |
| 速度與畫面 | 正常速度 1.0 倍、未水平鏡像、方向正確、正方形像素；無 replay／slow motion。 |
| 長度 | 每檔不超過 30 秒；長度必須容得下完整準備至收尾，不為縮短影片而剪掉動作。 |
| 聲音 | **不需要。** 有聲或無聲皆可，聲音不作為目前的投球判讀依據。 |

解析度與 FPS 的交付目標不代表新增自動拒絕門檻；足夠大的影片仍可能因模糊、遮擋或抓錯人而不能可靠分析。

## 4. 每顆球各一個檔案

- **需要每顆球各一個 MP4**，一檔只有一次完整投球；不直接接收含多顆球的合併影片作為分析輸入。
- 起點保留站定／準備與動作啟動，終點保留完整 follow-through 至恢復平衡；不能從抬腿之後才開始，也不能出手就截斷。
- 全段一個連續鏡頭；無切鏡、轉場、慢動作或同球重播。
- 投手從頭、肩至雙腳持續入鏡；保留動作需要的空間，避免放大裁切造成手、腳出框。

## 5. 隨影片提供的身分與時間資訊

每顆球需要一份與 MP4 配對的基本說明資料（JSON），包含：

- 唯一的單球編號、投手識別／姓名、左右投及正確的影片檔名。
- 拍攝角度，以及未鏡像、正常速度、單球、連續鏡頭、全身入鏡的真實確認。
- 球季、球隊、球種、場次／session 已知時提供；不從檔名猜測，未知就保留未知。

時間需求：

- 每檔以自己的第 0 格／0 秒為起點，保留真實 FPS、完整格數與逐格時間，能明確知道檔案的起訖。
- 若能提供原始長片中這顆球的起訖時間，請另保留供追查；目前不要求原始長片才能分析。
- 人工事件覆核需要：準備／啟動、最高抬腿、前導腳落地、大致出手、follow-through 結束。**這些事件不是供片的必填精確單格答案**；可在接收後人工補充。
- 如已標事件，另附人工事件紀錄，說明是本單球的 frame 還是秒數、以第 0 格起算，並保留判讀者、備註與不確定性。
- 看不清出手或跨兩格時可給 frame range；無法判定保留 uncertain／not observable，不以猜測或補影格製造精確時間。

## 6. 拍攝角度

- **目前正式接收只有 `rear_centerfield_broadcast`**：中外野後方轉播鏡位，從投手背後看向本壘，整次投球視角連續一致。
- 側面、正面、本壘後方、特寫等鏡位目前不屬正式分析輸入；不同視角不要混在同一球或同一批基準中。
- 優先鏡頭穩定、沒有大幅推拉或平移，投手身體足夠清楚且不過小。
- 正常自身遮擋可以保留，尤其投球手經過身前時；不能要求供片端猜出被遮住的肘／腕位置。與打者、捕手、裁判嚴重重疊的素材優先避免。

## 7. 最需要避免的錯誤

1. **錯的投手或身分／左右投資料不正確**：即使出現骨架，也不能當成指定投手的分析。
2. **錯的視角或切鏡**：同一骨架時間序列失去一致的畫面依據。
3. **準備或收尾缺失**：無法完整覆核投球動作與事件順序。
4. **慢動作、重播、鏡像或假影格**：時間與左右側判讀失真。
5. **模糊、投手過小、肢體出框或多人嚴重重疊**：可能漏點、錯點或把手臂標到別人的腳。
6. **檔名／說明資料不配對、錯誤時間單位或損壞檔案**：人工標註與分析結果無法對到正確素材。

## 8. 共用資料夾的交付要求

- 交付內容是一組可完整取得的單球 MP4 與配對 JSON；有人工時間紀錄時另附，清楚標明其對應單球。
- 每次交付有明確批次與每顆球的識別，完成後保持內容固定；更新以新批次提供，不無聲覆寫已標註影片。
- 多球合併影片可另作觀看用途，但不能取代逐球分析檔。
- 本文件只描述素材需求；共用資料夾接入仍待 Phase 2 穩定後另行驗證。
