# 人工事件四段動作摘要

更新：2026-10-26（台灣）。

原本只描述「落地→大致出手」，現在一次列出人工五事件之間的四段：

1. 啟動→最高抬腿。
2. 最高抬腿→前腳落地。
3. 前腳落地→大致出手。
4. 大致出手→收尾。

每段附原人工時距、投球肘／前導膝模型XY端點差、完整影格配對及缺值數量。
這是使用既有人工事件的描述，沒有自動判定投球階段、重跑骨架或要求新增標註。

## 如何解讀：以大谷001為例

下表為終點模型角度減起點模型角度。時距按原片60000/1001 FPS換算；表格只作顯示四捨五入。

| 人工事件區段 | 原時距（秒） | 肘端點差（度） | 前導膝端點差（度） |
|---|---:|---:|---:|
| 啟動→最高抬腿 | 0.517 | −0.3 | −88.1 |
| 最高抬腿→落地 | 0.851 | −94.8 | +81.0 |
| 落地→大致出手 | 0.150–0.167 | +152.4 至 +157.4 | +27.9 至 +33.4 |
| 大致出手→收尾 | 0.667–0.684 | −67.7 至 −62.7 | −42.3 至 −36.8 |

現在可分段查看變化，而不只看落地與出手。端點差為0也不表示期間沒有動作；
它不是期間最大活動幅度，也不是人體真實關節伸屈、動作品質或已校準的定位精度。
大幅投影角變化原樣保留，沒有據此自動判定模型標錯或動作較好。

相鄰段共用中間事件。中間事件為範圍時，各段獨立算出的差值上下界不能直接相加，
因為極值可能選用了不同的中間影格；本輪不組合整段候選路徑或計算跨段總幅度。
同一格參與多個配對，配對數不是獨立觀測數、機率或可靠性證據。
