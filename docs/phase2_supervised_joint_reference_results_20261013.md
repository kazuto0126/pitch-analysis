## 本輪完成了什麼

依[事前固定方案](phase2_supervised_joint_reference_plan_20261013.md)，實作可重現的三階段流程：

1. FIT 明示使用已有人工判讀，只從其他四片的 `reviewed_raw_observation` 建立六關節參考。
   原始來源 SHA 與衍生覆核檔先重建核對；全部 frame 0 排除，query 自己的人工標籤不參與自身界線。
2. APPLY 只讀封存數值與原模型量測，不讀 GT／覆核檔、不重新 FIT，逐格保存警示原因、
   原 observed／interpolated／missing、所有相容候選與時間。
3. 提示封存後才讀 query GT 評估。保存 592 格、3,552 關節列；完整 3,522 非 seed 列再依
   各關節人工可觀測性排除。模型缺值仍列在漏報／真負例分母，沒有只報有利影格。

參考仍固定為其他四片可信 raw 觀測的 finite min 分歧最大值；沒有依這次分數改選百分位、
重調界線或新增容忍數值。沒有變更既有 threshold、confidence gate、PitcherSelector、
pose／tracking、平滑或插值。這是**有監督的開發交叉驗證**，不能稱為整體 GT-blind，
也不能當成未見資料、第二投手或一般準確率的證明。

`within_reference_range` 只表示未超過這個實驗參考，**不等於 reliable**；候選歧義與缺值不強迫判對。
可信 raw 觀測也不能證明另一模型同格位置正確。比如 001／25 的肘 min 分歧為
0.13871125 倍畫面對角線，成為其他四個 folds 的最大參考；它自己的 query fold 用 002／139

腕同樣由 001／25 的 0.21123866 主導其他四個 folds。

兩個實際漏報案例：003／33 肘 min 分歧 0.030694（四捨五入）、004／28 為 0.057363，
都落在自身 0.13871125 參考內，人工原標籤仍是 `unreliable`。
