## 座標與追溯

裁切圖 native 33 點完整保存在候選側檔；同時保存轉回原圖的候選及實際 pixel bounds。
選取、clean、metrics 和 overlay 使用原圖座標，因此不把裁切圖座標錯畫到完整影片。

`x_original = (left + x_native * crop_width) / original_width`，Y 同理。
Z 只依 `crop_width / original_width` 換算原圖寬度歸一化尺度；仍是模型相對深度，
不代表校準 3D 或遮擋關節的真實位置。visibility／presence 原值保留；不 clamp、不人工補點。
既有 observed／interpolated／missing 規則保持；模型估出遮擋點並不等於直接可見或準確。
