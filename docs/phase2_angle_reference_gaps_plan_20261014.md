# Phase 2：既有2D角度差異的來源核對與反事實分解

2026-10-14。承接已封存的人工角度誤差評估，先確認影格／座標來源，再分解誤差。
這是相對既有人工2D參考的診斷，不是判定人工標點絕對正確，也不是修正模型座標。

## 事前固定範圍

- 只使用003完整115格、既有可見人工座標、原raw／processed及原角度評估。
  保留肘與前導膝兩項既有feature的230列；遮擋、uncertain、缺值與major限制原樣保存。
- 第69、105格的肘是前輪已記錄的案例；本輪在計算前固定，不另挑有利案例。
  主要分母仍是全部50格肘、106格膝的base／人工共同可比格；其他四球不套用003結論。
- 不產生新pose／tracker推論，不改原門檻、模型、選取、插值、平滑、GT或正式五球。
  不新增警示分類器，不以診斷結果自動更改eligible，也不進Phase3。

## 來源核對

逐格重解碼正式MP4，確認115格RGB與已封存輸入完全相同。核對人工image_name、
frame_index、timestamp、原PNG SHA及匯出manifest；對可見座標核對原CVAT XML與側別映射。
此核對只回答來源是否一致，不替使用者判斷點位或可見性。

## 反事實誤差分解

三點皆人工visible且非退化、原processed也有完整三點時，對3點的全部8個子集，
把子集內processed XY換成既有人工XY，計算相對人工角度的絕對誤差E(S)。
對全部6種替換順序平均每點帶來的誤差減少（Shapley分解）；保留負值與交互抵消。
三個貢獻之和應等於原絕對誤差。任何一個混合三點退化，整個歸因保持null，
不只平均有效順序；原角度誤差與分母仍保留。

混合三點不代表可實現的姿態、校正後預測或被遮住的關節，不能作為新的動作數據。
數值只表示「以這份人工座標為參考，替換該點的條件性影響」，不能認證某個人工點或模型點對錯。

## 同步保存的幾何證據

- 每點model-minus-manual XY與pixel距離；原raw／processed是否一致，與原observed狀態分開報告。
- 兩條ray在來源pixel平面的長度，以及manual→processed的有號方向差（atan2 cross/dot，影像y向下）。
- 未退化、非0/180度尖點時，保存三點局部unsigned-angle Jacobian與degree/pixel範數。
  端點範數是180/(pi×ray長度)；短投影肢段可能放大位置差，不能把它當人工誤差或信賴區間。
  精確0/180度的unsigned angle不可微，解析Jacobian保持null並註明原因。
- 不用任意pixel擾動製造準確度區間、不增加角度通過線、不用ray方向差代替完整角度誤差。
