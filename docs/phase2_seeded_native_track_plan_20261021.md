## 固定關聯政策（核准後才跑一次）

- 候選直接讀上一輪保存的eligible框；class0、score0.7與原ROI篩選結果全不變。
  不重跑detector、不讀GT，也不重算候選以改變上輪結論。
- 第0格以人工作業指定的output_index開始。
- 每兩個相鄰影格，計算其原候選框的標準intersection-over-union（IoU）。
  只有已連結的前格框與當格框彼此都是**唯一最大IoU，且交集面積大於0**，才延續。
- 若沒有正面積交集、最大值並列，或彼此不是對方唯一最佳重疊框，記track break。
  中斷後剩餘影格全部unlinked／missing；不自動重新捕捉或增加手動重設點。
- 不新增可調IoU門檻、加權總分、動作／服裝特徵、ReID、插值、HOG或CSRT。
  不根據這321格的結果調整政策。IoU是關聯依據，不是關節可靠度或身分機率。

框重疊仍可能因遮擋、框擴張或人物交錯而錯連，也可能過早中斷。
本次不把連續或有框當成可靠；完整保存候選關聯矩陣、選擇與中斷原因供影像檢查。
