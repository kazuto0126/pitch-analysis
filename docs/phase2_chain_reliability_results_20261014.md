## 方法與 scope

依[事前方案](phase2_chain_reliability_plan_20261014.md)，只測
`R=(鏈的兩段pixel長度之和)/(投球肩至前導髖的pixel距離)`。
每片使用其他四片全部依賴點都已有可信 raw 覆核的非seed格，固定最大值為上界；
自然投影縮短不設下界。FIT明示人工參考，APPLY不讀GT或view，不用native模型的位置或分數作決策。
原始 source 契約與SHA仍完整驗證；極小分母不clamp，零／缺值保持null。

提示只屬整條手臂或前導腿，不知道哪一端錯，不廣播為joint警示，不提升為major或identity switch。
主要人工目標是三個member任一unreliable為正例、三個皆reliable為負例，其餘按unknown排除。
query anchor人工狀態僅分層，不排除FP。保存1184列，完整1174非seed chain列及3522個原member標籤。

## 為什麼拒絕採用

- 手臂參考由005／44的1.44583887主導其他四片；005自己的上界是004／56的1.40053681。
  005／44超界仍是定性FP；其他118個有幾何值的手臂正例全在參考內，另外3格缺值。
- 腿參考由005／66的2.51634062主導其他四片；005自己的上界是002／151的2.12857822。
  小樣本正常投影包絡沒有充分區分錯點與自然動作。
- 軀幹anchor可能自然縮短或自己錯位；純長度比值對共同平移／縮放不敏感。
  本輪不能修復003整體偏移／104，也不證明可見性或投手身分。
- 保留前輪19筆局部定性FP與可見XY／major的不同參考用途，不改標、不挑更好比值或下界。
