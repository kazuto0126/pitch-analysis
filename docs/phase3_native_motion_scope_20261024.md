# Phase 3 第一個交付：單投手原生2D動作曲線

2026-10-24。使用者在確認保留現有大谷／山本骨架模式後，回覆「可以繼續下步驟」。
本輪開始先前提出的最小Phase3；Phase2原自動可靠性NOT PASSED的紀錄保持。
基底checkpoint：`48ac5bc`；開發分支：`codex/phase3-native-motion`。

## 本輪範圍

只使用已人工接受的大谷5支原生骨架，335／321／369／338／321格，合計1684格。
來源是已保存的native analysis input，沒有新增投手、供片接入、人物偵測或pose推論。
目前共用骨架方法、固定權重、人物框追蹤與原raw／GT完全沿用。

每支輸出完整0起算影格與分數FPS時間軸的兩條曲線：

- 投球側肩—肘—腕的2D夾角（肘為頂點）。
- 前導側髖—膝—踝的2D夾角（膝為頂點，前導側取metadata慣用手的對側）。

使用原圖pixel XY，重用既有幾何函數；不將17點補成33點、不套MediaPipe visibility gate。
原生score完整保留在來源，不用它推定人體可見性或新增可用門檻。
三點任一missing則角度留空，零長度肢段亦留空；不平滑、插值、重取樣或變動時間原點。

## 資料語義與限制

曲線值為`*_model_xy_deg`，表示「模型座標可計算的2D投影角度」。
`*_usable_deg`保持null，逐點可靠性unknown；原輸入的usable_for_analysis不被改寫。
整片人工接受與逐點可見／正確仍分開。模型對被遮住的點也可能給座標，因此曲線不是人體真值。
不宣稱3D生物力學、受傷風險、動作好壞或已校準的可靠度。

時間僅按每球起點計算秒數，不把五球自動對齊出手或投球階段。
不讀pipeline_anchors_sec、不猜出手／落地事件、不建立完整profile、比較排名或跨投手結果。
本輪也不重新打開Phase2已封存的分類器或改變驗收標準。

## 交付與驗證

新增讀取既有bundle的獨立命令`describe-native-motion`。
每球輸出逐格CSV、PNG曲線與來源綁定JSON摘要；五球提供簡單觀看頁。
數值計算需測手算角度、左右側、非方形原圖pixel、缺值／退化幾何、分數FPS與raw不變。
完整suite包含既有正式五球E2E；實際五球只計算曲線，不重跑骨架。
逐球列計算成功、缺點、退化幾何的完整分母；不將「計算成功」改稱「可靠」。
檢查實際曲線圖可讀性，更新current_status並commit／push後停止。
本輪只交付Phase3第一步，不宣告整個Phase3通過。
