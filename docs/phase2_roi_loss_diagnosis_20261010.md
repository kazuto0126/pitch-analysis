002的174格皆selected，右肘仍有15格由可用變低gate；這15個原IMAGE點全在裁切框內。
因此「selected格數」不能代表關節完整；「把原IMAGE點包回框內」也不能解釋所有損失。
模型上下文／縮放等可能影響輸出，但本診斷沒有隔離其因果，不能指定為已證實原因。

全部891筆損失中，原IMAGE預測514筆在框內、377筆在框外。這只是prediction proxy，
不能稱為377個真實可見肢體被裁掉。精確可見人工XY仍只有003，不將其他四片confidence當真值。
