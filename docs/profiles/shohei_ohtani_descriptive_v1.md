# 大谷翔平：五球動作特徵草案

更新：2026-10-26（台灣）。這份草案回答：**同一投手各球的哪些階段差異，在所有合法人工事件影格選擇下仍成立；哪些差異會隨選格改變？**

## 先看結果

本批五球的前段節奏並不相同。001／004的「啟動→最高抬腿」比其餘三球長；
005的「最高抬腿→落地」比其餘四球短。這兩項關係在既有人工事件允許的所有選格下都成立。
落地→出手則不能完整區分每球：002／003同為8格，001／005的範圍在10格相接。

模型投影也有共同端點變化：五球從最高抬腿到落地的肘角都減少、從落地到出手都增加。
前導膝仍需保留逐球差異：003從落地到出手的差值為負；005從最高抬腿到落地的正負方向受選格影響。
上述描述適用這五球的人工界線與保存模型座標，不代表投手所有球、真實人體伸屈或動作品質。

這是**時距關係**。即使差一格也會列出，但不增加「有意義差異」門檻，不視為統計顯著或表現好壞。
收尾時距依賴人工如何界定恢復穩定，也不能直接當成動作效率。

### 受選格影響：不能嚴格分出長短

- 啟動→最高抬腿：005〔14–18〕包含002的17格，也在14格與003相接；005可以比002短、相等或長，與003則可以相等或較長。
- 落地→出手：001〔9–10〕與005〔10–11〕在10格相接；005可以相等或較長，不能說一定較長。
- 002／003落地→出手都為8格，只表示記錄時距相同；不是整個動作相同的證據。

「不受選格影響」只表示關係在**目前已標的範圍**內成立，不包括尚未量測的人工標註誤差。
相鄰段共用同一事件；各段獨立上下界不能直接相加成一條完整候選動作。

## 肘與前導膝：共同變化及例外

下表的增加／減少皆指**終點模型XY角度減起點模型XY角度**，不表示真實人體屈伸方向，亦不表示期間曲線單調。
端點格號使用上列事件表，逐配對數值可回查來源CSV。

| 區段 | 投球肘的模型端點差 | 前導膝的模型端點差 |
|---|---|---|
| 啟動→最高抬腿 | 001／003為負，002／004／005為正，沒有全批共同方向 | 五球皆為負；001／004約−88.1°／−93.3°，002／003約−26.9°／−26.0°，005為−23.8°至−2.3° |
| 最高抬腿→落地 | 五球皆為負；005保留−81.8°至−72.6° | 001–004皆為正；005為−9.6°至+8.5°，方向受選格影響 |
| 落地→出手 | 五球皆為正，範圍內每個合法配對均如此 | 001／002／004／005為正；003為−7.3°，保留此例外 |
| 出手→收尾 | 003為+22.1°，其餘四球皆為負 | 003為+8.9°，其餘四球皆為負 |

005的膝方向不確定可直接回查：最高抬腿96–99格的模型角由122.1°到140.1°；
落地124格為130.6°。採96格作起點是增加，採99格則是減少，故不能選一個角度方向代表整個事件。
003的落地156格／出手164格前導膝為166.5°／159.2°，目前只能描述模型讀值減少，不能解讀成動作缺點。

## 資料不足：本草案不作的結論

- 球種、session等背景未提供，不能把差異全部歸因於動作不一致，也不能建立按球種的典型動作。
- 原生17點仍未有這五球的逐點精確度量測；遮擋、投影及定位誤差的影響無法單靠曲線分開。
- 只有後方影像的XY投影，不能推出真實3D角度、角速度、力量、傷害風險或動作優劣。
- 五球不代表整季或所有情境；沒有新增樣本、跨投手比較、品質總分或推薦排名。
